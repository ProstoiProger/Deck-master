Inter, JetBrains Mono, Source Serif 4, Playfair Display, Montserrat, Manrope and Unbounded were obtained as variable fonts from the Google Fonts repository (https://github.com/google/fonts)
and instantiated to static Regular (400) and Bold (700) instances with fontTools so that PDF generation can embed
them; no glyphs were changed. Press Start 2P and IBM Plex Mono are the unmodified Google Fonts files. Source Serif 4 was instantiated at optical size 24.

Each upstream project publishes its own licence text; keep it with any redistribution of these files.
