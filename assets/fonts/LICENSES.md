All bundled fonts are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org), which allows
use, embedding in documents and redistribution with the fonts unmodified in name or with the licence kept.

| Files | Family | Author | Source |
|---|---|---|---|
| `Inter-Regular.ttf`, `Inter-Bold.ttf` | Inter | Rasmus Andersson | https://github.com/rsms/inter |
| `JetBrainsMono-Regular.ttf`, `JetBrainsMono-Bold.ttf` | JetBrains Mono | JetBrains | https://github.com/JetBrains/JetBrainsMono |
| `PressStart2P-Regular.ttf` | Press Start 2P | CodeMan38 | https://github.com/codeman38/PressStart2P |

Inter and JetBrains Mono were obtained as variable fonts from the Google Fonts repository (https://github.com/google/fonts)
and instantiated to static Regular (400) and Bold (700) instances with fontTools so that PDF generation can embed
them; no glyphs were changed. Press Start 2P is the unmodified Google Fonts file.

Each upstream project publishes its own licence text; keep it with any redistribution of these files.
