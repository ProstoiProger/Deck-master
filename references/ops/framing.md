# Framing

Choose the story archetype before the outline. A perfect deck for the wrong story is wasted.

## Archetypes

| Archetype | Use when | Playbook |
|---|---|---|
| Product pitch | a thing was built and must be sold to judges or users | `playbooks/hackathon-pitch.md` |
| Findings report | an analysis produced insights for a decision maker | `playbooks/datathon-findings.md` |
| Assignment report | a marker checks coverage of a brief | `playbooks/assignment-report.md` |
| Defense | work must be justified against questions | `playbooks/project-defense.md` |
| Technical talk | peers learn a method or system | `playbooks/tech-talk.md` |
| Research talk | a claim is backed by experiments | `modes/research-talk.md` |
| Something else | none fits | `playbooks/novel.md` |

## Compare at least three candidates

Before settling, write each plausible framing in one line and score it.

| Candidate | Fits the audience's decision | Fits the rubric | Fits the material | Verdict |
|---|---|---|---|---|
| Product pitch | yes | demo and impact weigh 55% | working prototype exists | chosen |
| Findings report | partly | insight only 20% | analysis is thin | no |
| Technical talk | no | not a criterion | no | no |

## First-principles decomposition

1. The decision: what will the audience do or decide after the talk?
2. The evidence: what do you actually have that proves it?
3. The unit of attention: how many minutes and slides does that buy?
4. The risk: what will the audience doubt first?
5. The deliverable: file format, delivery, who else reads the deck without you.

## Re-framing triggers

The brief changes, the demo breaks, the key result does not hold, time is cut, the audience turns out to be
different. Re-run the comparison and tell the user what changed.

## Examples

| Request | Naive framing | Better framing |
|---|---|---|
| "slides for our ML project" | tour of the model | the decision the model improves, then evidence |
| "present my coursework" | chapter-by-chapter summary | rubric lines as the agenda, one slide each |
| "datathon deck" | all the charts we made | 3 findings, each number, interval, action |
