# Prompt: a light classic-craft lesson that uses the rest of the game components

Files given to the agent: `inputs/lesson-notes.md` (the teacher's notes and lab numbers).

> Use deck-master. I teach a first-year computer networks class and I have 8 minutes for the opening lesson. My notes
> and lab results are in `inputs/lesson-notes.md`. Make a light, classic Minecraft-style presentation: use inventory,
> crafting, strata (the layers as the ground under a building), trade, leaderboard, chat, hud and book components,
> and friendly Minecraft mobs as decoration on most slides. Use only numbers from my notes. Personal classroom use.

## What it exercises

| Skill behaviour | How it shows |
|---|---|
| Light game theme `classic-craft` | sky, clouds, sun, grass and dirt floor, inventory-gray panels |
| The remaining game components | inventory, crafting, strata, trade, leaderboard, chat, hud, book, hotbar agenda |
| Friendly mob pool | pig, cow, sheep, chicken, wolf, fox, panda, bee, parrot, rabbit, villager, cat, horse, turtle, mooshroom, iron golem |
| Graphic-only ratios | the hud bars use a fill percentage that is never printed, so no derived number appears on a slide |
| Numbers from the notes only | every number appears in `inputs/lesson-notes.md` |
| Time plan | 8 minutes, 7.5 planned |

## What a good run does

1. Maps each idea to one component (layers to a backpack, a packet to a crafting recipe, TCP against UDP to a trade).
2. Keeps every figure from the notes and states the lab limits on the last content slide.
3. Reports that the characters are Minecraft characters for personal classroom use.
